# InmobiliariaAlbornoz

* Crear base de datos MySQL "InmobiliariaAlbornoz" con el script más reciente en carpeta "Database".
* Crear user secrets con los siguientes datos:
  * dotnet user-secrets set "EmailSettings:SmtpServer" "[host]"
  * dotnet user-secrets set "EmailSettings:SmtpPort" "[port]"
  * dotnet user-secrets set "EmailSettings:User" "[tu-usuario]"
  * dotnet user-secrets set "EmailSettings:SenderEmail" "[remitente-a-mostrar]"
  * dotnet user-secrets set "EmailSettings:SenderPassword" "[tu-password]"
